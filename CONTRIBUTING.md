# Contributing

Thanks for helping improve DataSentry.

1. Open an issue describing the bug or feature before a large change.
2. Make focused changes and add tests for behavior that affects PII leaving the machine.
3. Run `pytest` and relevant optional integration tests when those dependencies are installed.
4. Keep examples synthetic. Never commit `.env`, API keys, or real personal information.
5. In a pull request, explain what changed, how you verified it, and any privacy or compatibility tradeoffs.

The MIT license in this repository applies to contributions submitted here.
